# 绘图提示词模板（中文）

组装完整的中文绘图提示词，调用 ImageGen 生成知识卡片。结构：**风格段 + 画幅段 + 主题色段 + 版式段 + 信息块段 + 角色段 + 连接段 + 结论条页脚段 + 文字约束段**。花括号 `{}` 为待填插槽。

## 完整模板

```
【画面风格】手绘涂鸦风教学知识卡片，如同用蜡笔、彩铅和马克笔在速写本上亲手绘制：线条带有自然抖动和不完美感，色块有手涂质感，边框为手绘圆角矩形，可轻微歪斜。整体温暖、治愈、亲切，像优秀老师的手写板书。禁止写实照片风、3D渲染风、商务扁平风、暗黑背景。

【画幅】横版16:9，浅色背景，留白充足（至少15%呼吸区），视觉动线自上而下：标题→中央图示→结论条。

【主题色】本卡主题色为「{主题色名}」：主色 {主色hex} 用于标题横幅、信息块描边、箭头和强调元素；深阶 {深阶hex} 用于标题文字和箭头描边；背景为该色系极淡 tint {背景hex}；信息块统一白底 #FFFFFF；正文文字用暖深色 #4A3F35。全卡色彩纪律：除主题色系外，只允许浅黄便签 #FCEBA8、木棕色 #A06B53、白色、蓝色小机器人和棕发小女孩的固有色，不得出现任何杂色。

【标题区】画面顶部通栏大标题，放在手绘丝带/横幅造型里（可轻微倾斜、有胶带粘贴感），内写口语化疑问句「{疑问句标题}」，粗体大字带轻微描边，用主题色；标题下方小字副标题「{副标题}」；画面{左上/右上}角贴1-2张黄色便利贴，写上补充提示：「{便签内容}」。

【中央图示·{版式名}】{版式描述，见下方变体}

【信息块】画面中布置 {N} 个白色圆角矩形信息块，主题色手绘描边，块内顶部是彩色粗体小标题，下方是圆点列表的短句，文字用深色；代码/API名用等宽字体标签样式呈现。各块内容：
1. 「{块1标题}」：{块1要点，用分号隔开的短句}
2. 「{块2标题}」：{块2要点}
{N. 「{块N标题}」：{块N要点}}

【角色】画面中必须包含：一个Q版可爱小女孩（{服装与职业}，{动作与表情}，粗描边、高腮红、弧线笑眼）；一个圆滚滚的蓝色小机器人吉祥物（{装扮}，{动作与表情}）。如有设备（笔记本电脑、手机等）请画上笑脸拟人化。

【连接元素】用粗壮圆头箭头/弧形箭头连接各元素，箭头带简短文字标签；角色头顶有对话气泡，写第一人称口语台词，例如「{台词}」。

【底部结论条】画面底部通栏浅黄色横幅 #FCEBA8，左侧一个发光灯泡图标，中间写一句话核心结论：「{一句话结论}」。

【页脚】最底部仅一行小字：「依据：{官方来源}」。除此之外不得出现课程名、课程序号、课纲等任何其他文字。

【文字要求】所有中文文字必须清晰、完整、无错别字、无乱码，关键术语与API名准确无误。
```

## 版式段变体（填入【中央图示·{版式名}】）

**A 流程分发型**
> 左中右三段式构图：左侧是「{左方角色/元素名}」（{一句描述}），中间是占据画面中心且尺寸最大的枢纽场景「{中央场景描述，含拟人角色}」，右侧是「{右方角色/元素名}」（{一句描述}）；粗弧形箭头从左指向中间标注「{标签1}」，从中间指向右标注「{标签2}」{，轨道下方加回程弧形箭头标注「{回程标签}」}。

**B 对比选型型**
> 顶部居中一句引导问题「{引导问题}」，下方 {N} 个等宽并列的信息块{，问题与信息块之间画分流箭头/漏斗，强调"一个问题分流到N个方案"}；每块含小图示+标题+适用场景+要点。

**C 双向回路型**
> 画面中央放置「{核心对象}」的大图示；上下各一条粗弧形箭头形成闭环：向下的箭头标注「{数据流标签}」，向上的箭头标注「{事件流标签}」；左右两侧分别是「{左侧组件/角色}」和「{右侧组件/角色}」；底部加 ①②③ 编号步骤条说明闭环过程：① {步骤1} ② {步骤2} ③ {步骤3}。

**D 旅程路线型**
> 画面中部一条横向手绘轨道从左到右贯穿，依次经过 {N} 个站点，每站一个圆形序号+阶段名图标+一句职责说明：1「{站点1}」{图标与职责} … {N}「{站点N}」{图标与职责}{；轨道下方画回程弧形箭头标注「{回程标签}」}{；背景从左到右表现时间流逝（昼→夜）呼应阶段语义}。

**E 中央隐喻大场景型**
> 一个占画面60%以上的大型生活化场景「{场景描述}」占据中心，知识点元素全部拟人化嵌入场景中；2-4个小信息块像便签一样贴在场景四周，只放关键词；台词气泡从场景角色口中说出。

## 填充示例（以「HTTP 请求的生命周期」为例，A 型 + 湖蓝）

```
【画面风格】手绘涂鸦风教学知识卡片，如同用蜡笔、彩铅和马克笔在速写本上亲手绘制：线条带有自然抖动和不完美感，色块有手涂质感，边框为手绘圆角矩形。整体温暖、治愈、亲切，像优秀老师的手写板书。禁止写实照片风、3D渲染风、商务扁平风、暗黑背景。
【画幅】横版16:9，浅色背景，留白充足。
【主题色】本卡主题色为「湖蓝」：主色 #69B8D8 用于标题横幅、信息块描边、箭头和强调元素；深阶 #2E7A9E；背景 #E8F4FA；信息块统一白底；文字用暖深色 #4A3F35。只允许浅黄便签、木棕色、白色、蓝色小机器人和棕发小女孩固有色。
【标题区】顶部通栏大标题放在手绘丝带里：「HTTP请求怎么到达服务器？」，副标题「网络编程基础 · 请求与响应」；右上角贴黄色便利贴：「真实网络还要经过DNS、TCP握手与TLS!」。
【中央图示·流程分发型】左中右三段式：左侧是「浏览器客户端」（一个画了笑脸的笔记本电脑），中间是占据画面中心且最大的「高速公路服务区收费站」场景（拟人收费员Robot匹配路径并转发），右侧是「Web服务器」（机柜画了笑脸）；粗弧形箭头从左→中标注「发请求」，中→右标注「转发」，下方回程箭头标注「返回响应」。
【信息块】3个白底圆角信息块：
1.「请求 Request」：方法 GET/POST；URL路径；请求头 Headers
2.「服务端处理」：路由匹配；业务逻辑；查询数据库
3.「响应 Response」：状态码 200/404；响应体；缓存头 Cache-Control
【角色】一个Q版可爱小女孩（穿蓝色制服，手指向中间的收费站，粗描边高腮红）；一个圆滚滚的蓝色小机器人吉祥物（穿收费员制服坐在收费站窗口）。
【连接元素】粗壮圆头箭头带标签；机器人头顶气泡台词「我按路径匹配并转发！」。
【底部结论条】浅黄色横幅+灯泡图标，写「客户端 → 服务端处理 → 响应返回客户端」。
【页脚】最底部仅一行小字：「依据：MDN Web Docs」。
【文字要求】所有中文文字必须清晰、完整、无错别字。
```

## ImageGen 调用与迭代策略

1. 调用 ImageGen 工具，将上述完整提示词作为 prompt 传入，指定横版 16:9 比例。
2. 若工具支持参考图：把 assets/ 中**版式最接近**的参考图一并传入，并设置较低的风格化强度（保留参考构图，不照抄内容）。
3. **文字保真**：AI 绘图对中文长文本支持有限。生成后逐字校对；错字 ≤2 处可在交付说明中标注「已知小瑕疵」或局部修正；错字 >2 处则重写该句提示词重新生成（最多 3 轮）。
4. 每轮重生成时，把上一轮的问题写进提示词做针对性修正（如「信息块描边加粗」「结论条文字再短一些」）。
5. 生成完毕按 SKILL.md 的校验清单自检，通过后交付。

## 命名规范

交付文件命名：`{课程序号}_{知识点}_{主题色}_{版式}.png`（课程序号可选，无课程信息时省略），例：`06_HTTP请求生命周期_湖蓝_流程分发.png` 或 `HTTP请求生命周期_湖蓝_流程分发.png`。
