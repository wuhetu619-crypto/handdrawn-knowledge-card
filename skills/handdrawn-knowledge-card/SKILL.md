# 手绘课堂知识卡片

生成「手绘课堂」系列风格的知识卡片教学图。风格规范已从 5 张实证卡片（assets/ref-01 ~ ref-05）完整萃取，新卡片必须与参考图保持同一风格语言。

## 参考文件索引

| 文件 | 内容 | 何时读 |
|---|---|---|
| `references/style-dna.md` | 风格基因：画风、五层骨架、标题句法、隐喻、信息块、角色、色彩纪律、负面清单 | 每次生成前必读 |
| `references/color-system.md` | 5 套主题色板（hex 值）+ 按课程序号轮换规则 + 全局固定色 | 选色时读 |
| `references/layout-templates.md` | 5 种版式原型（A 流程分发 / B 对比选型 / C 双向回路 / D 旅程路线 / E 中央隐喻）+ 判型速查 | 定构图时读 |
| `references/prompt-template.md` | 完整中文绘图提示词模板 + 版式变体 + 填充示例 + ImageGen 调用与迭代策略 | 组装提示词时读 |
| `assets/ref-01 ~ ref-05*.jpg` | 5 张实证参考卡（按课程序号命名） | 需要时可作风格参考图传入 ImageGen |

## 工作流

### 1. 收集输入
向用户确认（已有则跳过）：
- **知识点/内容**（必需）：要讲什么、包含哪些要点、示例代码/术语。
- **依据来源**（页脚用）：官方文档/教材出处，如「MDN Web Docs」「华为 XX 官方文档」。
- **主题色偏好**（可选）：默认按课程序号轮换（无课程序号时按知识点语义选色）。

### 2. 知识解构 → 选版式
判断知识点类型，对照 `layout-templates.md` 判型速查表选原型：
- 流程/机制/协议 → **A 流程分发型**
- 对比/选型/决策 → **B 对比选型型**
- 双向交互/状态流转 → **C 双向回路型**
- 阶段/周期/生命周期 → **D 旅程路线型**
- 概念科普/系统全景 → **E 中央隐喻大场景型**

### 3. 选主题色
按 `color-system.md` 轮换规则取色（默认：01 薄荷绿 → 02 橙 → 03 紫 → 04 珊瑚红 → 05 湖蓝，循环），记下主色/深阶/背景三个 hex。

### 4. 设计中央隐喻 + 撰写标题
- 为知识点设计一个生活化大场景隐喻（邮局、工坊、书架、回路、旅程等方向），把知识点元素拟人化嵌入。
- 主标题写成**口语化疑问句**；副标题给知识点坐标（「XX · YY」格式）。
- 结论条预写一句话核心结论（常为「A → B → C」式）。

### 5. 组装提示词
按 `prompt-template.md` 的完整模板填充所有插槽，把所选版式变体填入【中央图示】段。风格段、主题色段、页脚段、文字约束段**原样保留，不得删改**。

### 6. 生成
调用 ImageGen，传入完整中文提示词，指定横版 16:9。若工具支持参考图，同时传入 assets/ 中版式最接近的一张并设低风格化强度。

### 7. 校验（逐项自检，不达标回到第 5 步修订，最多 3 轮）
- [ ] 标题是口语化疑问句，在丝带横幅里
- [ ] 一卡一主色，背景淡彩，无杂色（色彩纪律）
- [ ] 有 Q 版小女孩 + 蓝色小机器人吉祥物
- [ ] 信息块白底彩边、圆点列表、代码用等宽标签样式
- [ ] 有粗箭头（带标签）或对话气泡（第一人称台词）
- [ ] 底部结论条：浅黄横幅 + 灯泡图标 + 一句话结论
- [ ] 页脚仅一行：依据 + 官方来源，无课程名/序号等其他信息
- [ ] 中文文字错字 ≤2 处（超过则重生成）
- [ ] 留白充足，画面不拥挤

### 8. 交付
按 `{课程序号}_{知识点}_{主题色}_{版式}.png` 命名保存（无课程序号时省略该段），向用户展示成品并说明已知小瑕疵（如有）。

## 铁律

1. 风格段、主题色段、页脚段、文字约束段在任何卡片中原样保留——它们是风格一致性的根基。
2. 一课一色，全系列五色循环，不随意破环。
3. 每张卡必须有角色、有场景、有隐喻，禁止纯文字图形排版。
4. 中文文字准确优先：术语、API 名、回调名一个都不能错，错字超标就重生成。
